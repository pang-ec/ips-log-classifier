# IPS Log Classifier

IPS 탐지 로그를 공격유형별로 자동 분류·집계하는 Python 스크립트

## 📋 프로젝트 소개

보안장비(IPS) 2대에서 각각 뽑히는 로그 CSV를 매일 사람이 눈으로 훑어보며
공격유형별 건수를 세어 리포트에 옮겨 적던 반복 작업을 자동화했습니다.

원래는 Dataiku DSS의 비주얼 파이프라인(Stack → Prepare → Window → Join)으로
먼저 설계·검증했고, 이 저장소는 그 로직을 재사용 가능한 순수 Python 함수로
옮긴 버전입니다.

## ✨ 주요 기능

- 서로 다른 장비에서 나온 CSV 여러 개를 하나로 병합
- 공격명/공격유형 키워드 기반으로 4개 카테고리 자동 분류
  (무작위대입공격 / 웹쉘공격 / 웹사이트위협공격 / DDoS)
- 로그 내용의 실제 타임스탬프에서 **가장 최근 날짜를 자동 인식**해 그 날짜만 집계
  — 파일명 규칙에 의존하지 않고, 폴더에 예전 파일이 남아있어도 안전
- 그날 발생하지 않은 카테고리도 0건으로 채워 항상 고정된 행 수로 출력

## 🛠 기술 스택

- **Language**: Python
- **라이브러리**: pandas

## 📦 사용법

```bash
python classify.py 장비1_로그.csv 장비2_로그.csv
```

출력 예시:

```
  IPS_분류  count
    DDoS      0
웹사이트위협공격     12
 무작위대입공격      1
    웹쉘공격      1
```

## 🧩 설계 메모

- **분류 우선순위가 결과를 좌우함**: Brute Force나 Webshell 키워드가 포함된 로그는
  공격유형 필드상으로도 "정보 수집"/"서비스 공격" 등으로 동시에 잡히는 경우가 있습니다.
  키워드 매칭을 먼저 확인하지 않으면 이런 로그가 전부 DDoS 쪽으로 오분류됩니다.
- **DDoS는 항상 0건 고정**: 별도 보안 시스템에서 이미 처리하는 영역이라, 이 파이프라인은
  일부러 DDoS를 집계 대상에서 제외하고 "처리 중"이라는 의미로 고정값 0을 출력합니다.
  기타 미분류 로그도 리포트에는 노출하지 않도록, 4개 지정 카테고리 외에는 결과에서
  제외했습니다.
- **날짜 필터는 파일명이 아니라 로그 내용 기준**: 처음엔 파일명에 날짜를 넣어 구분하려
  했지만, 운영자 실수로 파일명이 틀릴 가능성을 없애기 위해 로그 안의 실제 타임스탬프에서
  최댓값을 구해 그 날짜만 남기는 방식으로 바꿨습니다. 덕분에 예전 파일을 지우지 않고
  새 파일만 계속 추가해도 항상 최신 날짜 기준으로 정확히 집계됩니다.

## 배경

원본 설계는 Dataiku DSS 비주얼 파이프라인으로 진행했는데, 그 과정에서 DSS의 수식
언어가 `left()`, `lower()`, `formatDate()` 같은 흔한 문자열 함수를 지원하지 않아
`substring()`, `contains()` 조합으로 여러 번 우회해야 했습니다. 노코드 툴의 한계를
직접 겪고 나니, 같은 로직을 Python으로 옮기면 훨씬 안정적이고 테스트하기도 쉽다는
걸 확인하고 싶어서 이 저장소를 만들었습니다.
